Face and Eye Detection Project Report

This project combines Django, OpenCV, QR generation and a mobile-friendly workflow to register people, validate a face and both eyes, generate a QR identity, and retrieve a profile after scanning.

Objectives

  • Detect a human face and eyes from an uploaded or captured image.
  • Register a person with name, address, unique number and face image.
  • Generate a unique QR code linked to the registered profile.
  • Maintain registration and scan history.
  • Provide REST API endpoints for person data and face validation.

Working Flow

  1. User opens the Django dashboard.
  2. User enters name, address and unique number.
  3. User captures or uploads a face image.
  4. OpenCV checks for a face and both eyes.
  5. The person is stored in SQLite.
  6. A QR code is generated for the profile URL.
  7. Scanning the QR opens the profile and records scan history.

Advantages

  • Simple and understandable student/project implementation.
  • Combines computer vision, web development and QR workflows.
  • Supports browser camera capture and mobile profile access.
  • Keeps a basic audit history of registrations and QR scans.

Limitations

  • Haar cascades are less accurate than modern deep-learning detectors.
  • Detection depends on lighting, camera quality and face angle.
  • SQLite is suitable mainly for development and small deployments.
  • Production use should add stronger authentication, privacy and security controls.

Conclusion

The system demonstrates a complete face-and-eye detection workflow integrated with Django and QR identity generation. It is suitable for learning, demonstrations and prototype identity-registration applications.
